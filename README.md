Fullstack app showcase latest tools.

### To use pretty printed messages please add variables to your shell:

```bash
# for bash:
echo 'export FORCE_COLOR=1' >> ~/.bashrc
source ~/.bashrc
# for Zsh:
echo 'export FORCE_COLOR=1' >> ~/.zshrc
source ~/.zshrc
```

```fish
# for fish:
set -Ux FORCE_COLOR 1
```
